# FORMA — Premium Website Redesign Concept

A responsive, single-page studio website concept created as a contest-ready visual direction.

## Files
- `index.html` — complete page structure and content
- `assets/style.css` — visual system, responsive layouts and interactions
- `assets/script.js` — mobile navigation and FAQ accordion behaviour

## Preview
Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted imagery, so an internet connection is required for those assets.

## Design direction
- Warm off-white canvas, deep charcoal typography and restrained botanical-lime accents
- Manrope display typography, DM Sans body copy and DM Mono labels
- Editorial split layouts, asymmetric project grid, generous spacing and subtle hover states
- Responsive navigation, project cards, services, process, journal, FAQ, contact and footer

## Customisation
Replace the FORMA name, copy, email address and image URLs with the client's supplied brand assets and content. This is an original concept direction, not a claim about the client's existing brand.
